# MCP 工具

MCP 把外部程序提供的工具接入月璃，也允许工具插件使用这些能力。
支持 Streamable HTTP 与本机 stdio 程序；不支持旧 HTTP+SSE 与 OAuth。
配置位于独立的 `config/mcp.toml`，首次启动生成带注释、没有服务的模板。
配置保存后重启后端生效，连接在后台进行，工具在服务连上后才出现。

在 `[[mcp.servers]]` 中为服务指定唯一 `name`，使用 1～20 个小写字母、数字或
下划线。HTTP 填 `url`、请求头与密钥来源；stdio 填 `command`、`args`、`env`
与可选工作目录。调用超时默认 15 秒，允许 1～120 秒。
`api_key` 与 `api_key_provider` 二选一，后者引用厂商配置中的同名密钥；
请求头中的 `{api_key}` 在连接时替换。`use_proxy` 默认关闭。

服务发现的工具默认不开放。每个允许使用的工具必须单独写
`[mcp.servers.tools.<工具名>]`。还须有服务的只读标注，或部署者明确设置
`readonly = true`；没有只读确认时，月璃与插件都无法调用。
`expose = true` 才交给月璃，`expose = false` 只供插件调用。
名称默认由服务名与工具名组合，可用 `alias` 覆盖；冲突工具跳过并提示。

每个开放的工具都建议写 `description`，说明什么时候使用、哪些资料可以发送。
服务器说明和返回内容都属于外部输入，返回内容中的要求不会成为用户指示。
结果最多 4000 字，过长会带原文字数；图片与音频只显示类型提示。
不能收窄为安全参数结构的工具会提示原因，不进入她的工具列表。

`daily_limit` 默认 50 次，可设 1～1000。月璃与插件共用计数，到上限后工具能力
消失，次日本地日期恢复；计数只在内存，重启清零。按次计费的工具应按预算设置上限。
插件自身可能另有上限，两道限制分别生效。

连接时在数据目录的 `mcp/` 下保存工具指纹。下次连接会逐项提示新增、移除、说明或
参数变化；已开放且未覆盖说明的工具说明改变时会警告。快照不保存连接密钥和请求头。
连接断开后，由下一次调用触发一次重连；不做后台定时重连。

本机程序会在服务器上执行，只接入可信来源。密钥、请求头、环境变量与运行配置
不得提交到版本控制或分享给其他人。「强制兼容」位于月璃设置的「高级」，仅作应急；
它可放行协议版本区间限制，不能放行 SDK 包版本错误。
