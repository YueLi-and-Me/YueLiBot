# providers.toml：厂商连接

真实文件是 `config/providers.toml`，每个 `[[api_providers]]` 是一条可复用连接。
同一连接可以供多个模型使用，换密钥不必逐个编辑模型。
逐字段说明见[厂商模板](../../../config.example/providers.toml)。

## 连接名、预设与实际地址

`name` 是模型引用的唯一名称；`kind` 是地址预设标识，两者职责不同。
首装两者都写 `dashscope`，但不要求永远同名。
`base_url` 非空时使用显式地址；留空才按 `kind` 查内置地址。
未知预设加空地址无法使用，选用的候选会在配置加载时暴露该问题。

改 `kind` 不会覆盖你已经填写的 `base_url`。
换服务时检查地址、鉴权、模型 ID 和额外参数是否整套匹配。
兼容接口通常填写服务基础地址，不要再拼上完整聊天方法路径。
内置预设只提供地址，不会为你开通账号、密钥或模型权限。

## 四种鉴权方式

下表适用于 `client_type = "openai"` 的兼容接口。

| `auth_type` | `api_key` | `auth_name` | 实际含义 |
| :--- | :--- | :--- | :--- |
| `bearer` | 必填 | 必须空 | 通过 Authorization Bearer 发送密钥 |
| `header` | 必填 | 必填 | 通过指定 HTTP 头发送密钥 |
| `query` | 必填 | 必填 | 通过指定查询参数发送密钥 |
| `none` | 必须空 | 必须空 | 不添加身份凭据 |

不能保留 bearer 再清空密钥来表示本地免鉴权。
也不要同时在 `default_headers` 中手工再写一套认证头。
额外请求头和固定查询参数分别放在 `default_headers`、`default_query`，
只填写服务端明确要求的键，鉴权仍由三个专用字段管理。

面板读配置时不回传明文 Key；已存条目编辑时密钥框留空表示保留原值。
直接编辑 TOML 时没有这种含义：把 `api_key` 清空就是把磁盘凭据清空。
面板把连接改为免鉴权时会清空原密钥，同时应清空认证字段名。
面板保留密钥按连接名称匹配；改名时要重新填写密钥，不能留空期待沿用旧名的凭据。
配置与备份都含真实凭据，不提交到版本控制。

## 超时和安全重试

`timeout_ms` 默认 120000，约束单次 HTTP 连接与流式读取。
`max_retries` 默认 2，是尚未产生可见内容时，同一连接内允许的重试次数。
`retry_interval_ms` 默认 800，是重试间隔。
重试次数不是总尝试次数，也不是任务备用模型的数量。

任务首字窗口会覆盖这些重试：任务只等 30 秒时，不能保证跑满连接的全部重试。
调参前先看失败是握手、鉴权、模型参数、服务端错误还是等待过久。
鉴权和请求格式错误不会因延长等待而解决。
普通流式内容一旦开始输出，中途出错不会从头重试复制一遍回复。
候选切换与慢响应记录见[模型配置](models.md)。

## 本地推理服务

先单独启动能提供兼容接口的本地服务，记下实际地址和模型 ID。
以下是一条免鉴权连接示例，端口 8000 必须替换为实际监听值：

```toml
[[api_providers]]
name = "local"
kind = "openai"
base_url = "http://127.0.0.1:8000/v1"
api_key = ""
auth_type = "none"
auth_name = ""
client_type = "openai"
```

这段加在已有 providers 文件内，保留原有 `[inner]`。
再在模型目录将目标条目的 `api_provider` 设为 `local`，
真实模型 ID 填本地服务接受的名称，并分配给任务。
不要给本地服务发送它不认识的百炼 `extra_body` 参数。

`127.0.0.1` 指后端所在的机器；容器里的本地地址不等于宿主机。
如果模型服务在另一台机器，填写后端能访问的地址。
程序不会替你启动本地推理服务，也不会因为选了免鉴权就检查服务是否只对内开放。

## 模型列表与协议类型

`model_list_endpoint` 默认 `/models`，用于面板连接测试与拉取目录。
服务没有实现目录接口时，拉取失败不能单独证明聊天接口也不可用。
目录成功返回同样不证明其中每个模型支持视觉、工具调用或嵌入。

`client_type = "openai"` 对应兼容接口，可承载对话、视觉、嵌入和语音。
`client_type = "volcengine"` 使用专用语音协议，只能绑定 tts 任务。
后者还要填写 `app_id` 与作为访问凭据的 `api_key`，
音色和集群则在[功能配置](features.md)中填写。
不能把语音专用连接分配给日常对话候选。

## 保存与核对

只改连接名时，也要更新每个引用它的模型。
保存并重启后端，先确认没有悬空引用与凭据校验错误。
再用实际任务验证接口，结合调用记录看服务端返回原因。
首装六个模型共用一条连接，这条连接不可用会同时影响它们。
有多条连接时，故障隔离按厂商连接名称处理，具体策略见[模型配置](models.md)。
