# 环境要求

**操作系统** —— 桌宠要 Windows 10 / 11；只跑后端的话 Linux 也行。

**Python** —— 3.11 以上，由 uv 自动准备，不用自己装。

**Node.js** —— 22 以上。管理面板与桌宠要用它构建一次。

**磁盘** —— 留 3 GB 以上。

**内存** —— 4 GB 以上。

**两个 QQ 号** —— 一个当机器人（建议用小号，接入 QQ 有账号风险），一个是你自己。
两个号必须不同，协议端登录的必须与配置里写的一致。

**一个 API Key** —— 默认走阿里云百炼，到[百炼控制台](<https://bailian.console.aliyun.com/>)开通并创建一个，
形如 `sk-xxxxxxxx`。用别的厂商见 [providers.toml](../configuration/providers.md)。

**项目目录不要放在 C 盘** —— 桌面外壳拒绝把运行时文件写进系统盘，放在 C 盘以后开桌宠会直接报错。
只跑后端不受这条限制。
