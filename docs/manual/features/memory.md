# 记忆

她记住三类东西：刚聊了什么、这段日子发生过什么、关于你的事实。另外还有一个不放「记忆」而放「资料」的知识层。
本页说明每层存什么、怎么被想起来、会不会忘、你在面板上哪里查和改。

默认状态：记忆全程默认开启，没有总开关；能调的是各层召回的数量与节奏。
关掉的方式是把对应召回数量调 0，代价见文末。

## 三层记忆各存什么

**工作记忆**：当前会话的原始消息，逐条保存。每轮回复时取最近若干条送进模型，
条数由 `bot.toml` 的 `conversation.working_memory_messages` 决定（默认 40）。
消息被摘要归档后退出这个窗口，但原文不会删除。

**情节记忆**：一段时间里发生的事的摘要。未摘要消息攒到 `conversation.summarize_trigger_messages`
（默认 48 条）后，后台把最老的一批（默认 16 条）交给模型写成一段情节，连同召回线索一起入库。
情节不随时间衰减。

**事实记忆**：关于某个人的结构化事实——身份、偏好、关系、习惯、事件、状态。
累计 `conversation.fact_extract_trigger_messages`（默认 32 条）消息后回看一次并抽取。
每条事实带强度、半衰期、来源场合，会随时间淡化（见下节）。

**知识层**不是记忆：它存你通过导入中心喂给她的资料（设定、文档、笔记）。
知识不衰减、不参与遗忘，也不会在每轮对话里自动出现——她在需要时主动查阅。

## 她怎么想起来

每轮回复前，用当前消息和会话印象做检索词，在「在场者」（当前说话人加最近发言的人）的事实里搜，
再按相关性与新鲜度排序。四个键控制进提示词的数量（都在 `bot.toml` `[conversation]`）：

- `fact_recall_limit`：每轮最多召回几条事实，默认 6。
- `recalled_episode_limit`：按当前输入相关性召回几条情节，默认 2。
- `recent_episode_limit`：无论相关性都补充几条最近情节，默认 2。
- `episode_context_limit`：两路情节去重后写入提示词的总上限，默认 3。

开启[向量召回](index.md)后（`features.toml` `vector.enabled`，另需安装 vector 可选依赖与 embedding 任务档），
在既有候选上叠加语义排序：相关性按词面匹配与向量余弦 0.4/0.6 加权融合。关闭或向量不可用时退回纯词面匹配，
事实照样能召回，只是排序粗糙一些。

隐私边界：事实记录来源场合。私聊里听到的事实默认不进群聊提示词，
想放开把 `conversation.private_facts_in_group` 设为 `true`；群聊来源的事实两边都可见。

## 她会忘掉什么

事实走遗忘曲线：留存度按半衰期指数下降，提到、用到会强化回升。
半衰期按事实类型分档：身份与日期约一年，偏好与关系 90 天，习惯 60 天，事件 21 天，状态 12 小时。
跌破冻结线的事实停止参与召回；再次被写入或命中时复活。冻结不是删除——行与历史都保留。

真正会删数据的只有两处：你在记忆管理里逐条删除，或导入中心整批撤销（知识层按批物理删除）。
表达方式另有 30 天未确认且未使用即自动淘汰的规则，见[表达方式与黑话](expression-jargon.md)。

## 面板上哪里查和改

- **人物与关系**：按人看她记住的事实，含内容、类型、保留度与状态，只读。
- **记忆管理**：逐条标失效、恢复、永久保留、用新正文取代旧事实；同槽位冲突的事实成组裁决；
  每次操作都进流水，可逐条撤销。自动纠错做的取代也落同一条流水，同样可撤销。
- **记忆联想网络**：三层记忆之间的关系图，选中节点可预览一次真实的联想扩散。
- **导入中心**：粘贴文本或上传文件进知识层，按批预览影响面、整批撤销。
- **检索调优**：召回参数（含三个召回数量键）的扫描、对照与配置档保存；
  保存的是运行期覆盖，不改 `bot.toml` 文件本身。
- 五个页面的入口说明见[面板总览](../webui/index.md)。

## 怎么调、调没了会失去什么

- 想让事实进得少一些：调小 `fact_recall_limit`。调 0 后系统提示词里不再有事实块，
  她只剩工作记忆和情节，表现为「聊过的具体事情记不住」。
- 两个情节键调 0：提示词里不再出现情节，她失去「这段日子发生过什么」的中期记忆。
- 三个召回键全部调 0 等于关闭被动记忆注入；她的行动核心主动检索不受这几个键影响。
- 摘要与抽取的节奏由 `summarize_*` 与 `fact_extract_*` 四个键控制；调大触发条数会推迟归档，
  工作记忆窗口相应变长。

实现细节（遗忘曲线公式、联想扩散算法、反馈纠错链路）见[开发手册·记忆系统](../../dev/architecture/memory.md)。
