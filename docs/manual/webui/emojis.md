# 表情包库

她能发出去的表情都在这里；语义标签、使用计数与目录占用一目了然。本页是表情包的
唯一管理界面，容量、收集与淘汰参数在[月璃设置](settings.md)的表情包库段。

## 顶部总览

五张统计卡加一条容量条：

- **库内记录**：当前收录张数，附已封禁数——封禁的还在目录里，但不占容量配额。
- **封禁哈希**：按内容哈希封禁的数量，独立于记录存在——同图即使重新收录也会
  被拦。
- **目录占用**：表情包目录的磁盘占用与文件数。
- **孤儿文件**：目录里有、库里没记录的文件数与体积；后台清理任务按设置页的节奏
  处理它们，这里只报数。
- **库容量（不含已封禁）**：进度条显示当前容量对上限的占比。满了之后新表情收不
  进来，既有条目按「最少被使用」先淘汰——把排序切成「按使用次数」升序，页面上
  越靠前的条目就是真的会先被淘汰的条目。

## 列表

页签按封禁状态分（全部 / 未封禁 / 已封禁 N），排序可按收录时间或使用次数，两个
按钮再点一次翻方向。翻页、全选与批量操作的行为与其它列表页一致，勾选集跨页
保留。每张卡片是缩略图加三行信息：

- **语义标签**：收录时自动生成的情绪描述（如「无奈」「尴尬」「卖萌」），发送时
  按情绪匹配挑图。
- **她用 N 次 · 见到 N 次**：她实际发送的次数，与这条表情在会话里被见到的次数。
- **最后使用**：最近一次发送时间；从未发过显示「—」。

## 封禁与删除

「已封禁」页签集中列出全部封禁条目，逐张解封或批量解封都在这里做。行内**封禁**
与**删除**各带确认弹窗；「全选本页」后顶栏出现批量封禁 / 批量解封 / 批量删除
（按钮标注影响张数）。两条路的效果不同：

- **封禁**可逆，解封即回。封禁后这张图不再被发送，但文件与记录都留着，不占容量
  配额；同内容的图按哈希一起拦。
- **删除**不可逆，文件与记录一起走。想回收磁盘空间用删除；只是不想让她发某张图
  用封禁。

封禁是可审计的：页签与统计卡里始终能对上封禁总数，解封只解除发送限制，不改变
使用计数与标签。删除则连哈希一起处理——同图日后重新出现会作为新记录重新收录、
重新打标签，这是它与封禁最大的行为差异。

每页 24 张，底部翻页。批量删除把当前页删空时，页码自动夹回新的末页，不会停在
空白分页上。刚部署还没有会话数据时，列表为空，统计为零——表情包是会话里见到
新图时按设置页的收集参数收录的。

## 孤儿文件从哪来

库以记录为准，不认目录里多出来的文件。手动往表情包目录里拷图、或绕过面板直接删
文件，都会造成「目录有、记录无」（或反之）的孤儿。清理任务按设置页配置的节奏与
保留期处理，本页的孤儿文件卡片是核对清理效果的读数——正常情况下它应该长期是 0。

## 相关参数

收录开关、容量上限、淘汰节奏与孤儿清理的保留期都在[月璃设置](settings.md)的
表情包库段（`bot.toml`）。这里只改单张图的状态，批量上限与自动淘汰要在那边调；
改完同样要重启后端生效。
