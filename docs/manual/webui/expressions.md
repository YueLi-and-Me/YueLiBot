# 表达方式

她说话时可选的说法与适用情境，从真实会话里学来，回复时按情境加权选用。与
[黑话词表](jargon.md)的分工：黑话解决「某个词指什么」，本页解决「一句话怎么说」，
两张表独立学习、互不依赖。选择与学习的实现见
[core-agent 模块](../../dev/modules/core-agent.md)；一次选择过程对应
[会话观察](observe.md)事件账本里的「表达方式选择」「表达方式学习完成」事件。

## 条目长什么样

每行一条：表达式本体（如「翻译成人话：后接通俗解释」）、用过次数、学到时间、
范围（全局或具体会话）、来源标签、复核状态，以及一句**适用情境**——学习时归纳
的「什么场合该用它」，也是选择模型挑选时的判据之一。列表按行排版而非卡片网格，
一屏能过几十条，批量清理时配合排序翻页效率更高。

## 「在用」与「在学」

这是两件事，页面用两个数字分开表述：

- **用过**：回复生成真的选中这条的次数。选择链路是候选池加权抽样、再由选择模型
  挑一条，选中会回写使用次数与最后使用时间。
- **学到**：后台学习任务从对话里提取到这条的时间。来源标「本机学习」的是本部署
  学来的；按确定性规则，从未被选中且过了保留期的本机条目会被自动淘汰——迁移
  存量一条都不会被自动清理，防止把某个会话的候选池清空。

## 复核

页签按复核状态分：**全部**、**未复核**、**已确认**、**已驳回**。复核不是使用的
前置条件——未复核的说法照常进候选池，复核的职责是剔除与保护。页签计数帮助估算
待处理量，日常浏览用「全部」，集中清理时切「未复核」。三种动作各管一件
事，行内与批量两条路径语义一致：

- **确认**：永不自动淘汰，用来锁住特别贴的说法。
- **驳回**：退出候选池但保留行，整行置灰并标注「不再生效」；学习器再学到同样的
  说法会被唯一约束挡住。批量驳回是清理噪声的主力——它不删行，不会把某个会话的
  候选池清空。
- **删除**：不可逆移除，同样的说法日后可以重新被学到；清理迁移存量走这条。

「全选本页」勾选后顶栏出现批量确认 / 批量驳回 / 批量删除。批量删除后，页面对
候选数跌破起用下限的会话会如实报出——那些会话的表达注入会停摆，直到重新攒够
候选。看到这条提示不必补救性乱删：要么继续正常聊天让学习器补货，要么从回收的
迁移存量里确认几条回来。

## 筛选与排序

「会话」下拉按会话过滤；排序默认按学到时间倒序（后学到的在前），可切换按使用
次数排，两个按钮再点一次都翻方向。列表分页。排序的两个实用方向：降序找最常被
选中的说法，升序找从未被选中的清理对象——配合「全部」页签加批量驳回，一轮就能
把候选池过一遍。

## 生效范围与空态

范围标「全局通用」的说法在任何会话的候选池里都可能出现；会话级条目只在对应的
私聊或群里参与抽样。新部署的库这里为空：表达学习在真实对话的回合收尾处后台进行，
聊得越多，候选池越满。

确认锁定一个典型用法：她某句接话特别贴（比如「给你上了点科技」用于展示技术成果
时），确认之后自动淘汰永远不碰它，不用隔一阵就重新找回。相反，学来的一句书面腔
不像她会说的，驳回置灰即可，不必删——万一学习器又学到同样的说法，唯一约束会
挡住它。确认与驳回都不改写条目正文，只改它进不进候选池。
