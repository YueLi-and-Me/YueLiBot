# 导入中心

把外部资料成批写进知识层（第三层「知识」记忆），按来源批次整批撤销。三层记忆的
分工见[记忆系统](../../dev/architecture/memory.md)；导入的去重与向量化复用运行期
同一条链路，不走特殊通道。

## 导入

两种入料方式：

- **粘贴**：大文本框直接贴，**空行分段，一段一条知识条目**。例如一段一行地贴
  「群的固定规矩」「某个圈内术语的解释」，中间空一行。
- **文件**：点「选择文本文件」上传纯文本文件，分段规则相同；来源名取文件名。

硬上限页面写明：单次粘贴 200,000 字符、文件 2000 KB、单批 5000 条。超出单批上限
的大部头分多次导入——每一批独立成行、独立可撤销，这也是把不同来源分开导入的
理由。点「导入粘贴内容」后进入后台处理，页面提示「分块、去重与向量化，完成后
自动刷新批次列表」，期间可以切走。

完成后显示四个指标：**提交条目**、**实际新增**、**去重丢弃**、**向量化成功**。
去重丢弃是内容与库里已有条目重复而被跳过的部分；向量化未成功的条目仍会入库，
只是暂时不参与向量召回。

## 来源批次

每批一行：批次号、来源（粘贴时是来源名，文件导入时是文件名）、状态（进行中 /
完成 / 失败）、`N 提交 / N 新增 / 现存 N`、时间与摘要。「现存」是这一批到当前
还活着的条目数，会随后续管理操作变化；同一来源多次导入是各自独立的批次。两处
细节：

- 实时条数为零的批次不再列出；无批次的老存量（升级前入库的知识）不受任何删除
  影响。
- **删除该批**先出预览：确认框写明「将删除 N 条知识条目，删除后无法恢复（可重新
  导入）」。删的是这一批当初新增的条目，不是按内容猜的相似条目。

撤销整批不影响其它批次与其它记忆层；删错了且原文件还在，重新导入一次即可，重复
条目会被去重拦下。注意知识层条目在面板里没有单条编辑入口——这一页的整批撤销就是
唯一的删除路径，导入前把分段与内容过一遍，比导错了再撤省事。

## 向量化与召回

导入走的去重与向量化是运行期同一条链路：每条目按内容查重，新条目交给嵌入模型算
向量。算成向量的条目才能吃到向量混合召回（开关见[月璃设置](settings.md)的功能
开关页签）；没算成的先挂在库里，等补算跑过之后自然并入。四个结果指标就是对这
一趟的逐段计数，某一段数字明显偏低时先看嵌入模型的连通性，再回
[模型与厂商](models.md)页测连接。批量导入大语料前，先贴一小段试跑一遍，确认
分段粒度与去重结果符合预期，再整批导入。

## 什么时候用

迁移旧语料、灌入领域资料、批量补常识时用这一页；单条事实的失效与取代在
[记忆管理](memory-manage.md)页，导入后的成网效果在[记忆联想网络](memory-graph.md)
页看。

## 空态

还没有导入过批次时，来源批次区只有一句空态提示；导入区的两个按钮在文本框为空时
置灰。第一次导入完成后，新批次立即出现在列表顶部，四项指标同时显示在该页的导入
卡片里；右上角的「刷新」随时可重读批次列表。导入区与批次区同屏，导入完成后不用
切页就能核对结果。
