# 管理面板

浏览器里的观察与配置入口：怎么进、每页做什么、监听范围与鉴权方式。启动方法见
[从零跑起来](../deployment/first-run.md)；页面背后的实现见
[可观测性](../../dev/architecture/observability.md)与
[webui 模块](../../dev/modules/webui.md)。

后端启动时会在控制台打印面板地址与 token（默认 `http://127.0.0.1:7999`）。

**本机用浏览器打开会自动登录**，不用手输 token：请求来自回环地址时后端直接建立会话。
需要手输的只有两种情况——自动登录不可用时（面板会明说），以及直接调 API 的时候
（`Authorization: Bearer <token>`）。

token 由 Python 生成、每次启动重新生成，落在 `data/runtime/backend.json`，不会写进
日志或事件流。

## 按需求找页面

| 你想做的是 | 去哪 |
| :--- | :--- |
| 看她此刻在哪一步、上一轮为什么没回 | 会话观察 |
| 换模型、加厂商、调某个任务的温度 | 模型与厂商 |
| 看她对我的印象，或某个人的好感度 | 人物与关系 |
| 管她学来的群内说法与说话方式 | 黑话词表、表达方式 |
| 改一条记错的事实、裁决两条打架的事实 | 记忆管理 |
| 批量灌入资料、撤掉一次错误的导入 | 导入中心 |
| 让某类记忆更容易被召回 | 检索调优 |
| 禁止或解禁某个表情 | 表情包库 |
| 改群聊触发、感知出口这类行为开关 | 月璃设置 |

## 通用控件

- 右上角「切换明暗主题」按系统偏好初始化，点击在明暗两套之间切换。
- 「登出」作废当前浏览器的会话凭据，回到登录页；本机刷新页面会再次自动登录。
- 列表类页面共用同一套翻页条：上一页 / 下一页 / 回到第一页，并显示总条数与页码。
- 带勾选框的列表支持「全选本页」加批量操作；勾选集跨页保留，换筛选条件时清空。

## 监听与鉴权

面板只监听 `127.0.0.1`，所有接口过 token 鉴权；浏览器拿到的是独立会话凭据
（HttpOnly Cookie），不是后端的主 token。监听地址没有配置项可改，远程访问走 SSH
端口转发，见[无头部署](../deployment/headless.md)。

写类接口里有比鉴权更严的一条线：提示词覆盖的保存与恢复只接受来自回环地址的请求，
其它来源一律 403。连不上面板、页面异常之类的症状见[常见问题](../troubleshooting.md)。
