# 管理面板

浏览器里的观察与配置入口：登录方式、各页面的用途，以及监听范围与鉴权约束。

后端启动时会在控制台打印面板地址与 token（默认 `http://127.0.0.1:7999`）。

**本机用浏览器打开会自动登录**，不用手输 token：请求来自回环地址时后端直接建立会话。
需要手输的只有两种情况——自动登录不可用时（面板会明说），以及直接调 API 的时候
（`Authorization: Bearer <token>`）。

token 由 Python 生成、每次启动重新生成，落在 `data/runtime/backend.json`，不会写进
日志或事件流。

面板页面：

| 页面 | 用途 |
| :--- | :--- |
| 会话观察 | 管线阶段板、事件账本检索、提示词工作台、实时日志；每一级模型调用的完整输入输出都能翻回来看 |
| 模型与厂商 | 厂商与模型目录、各任务的候选清单与采样参数 |
| 人物与关系 | 她记住的人、各自的关系状态与事实 |
| 黑话词表 | 学到的群内说法与命中情况 |
| 表达方式 | 学到的说话方式与被选用的次数 |
| 记忆联想网络 | 记忆之间「总是一起出现」的边与扩散路径 |
| 检索调优 | 召回参数扫描与效果对照，带留痕重放 |
| 导入中心 | 粘贴或上传资料入知识层，按批次预览与整批撤销 |
| 记忆管理 | 按人看事实，标失效 / 恢复 / 永久保留 / 取代，冲突组一键裁决与操作撤销 |
| 表情包库 | 表情包目录与语义标签 |
| 月璃设置 | 五份 TOML 的读改存，含群聊、感知出口与主动互动开关 |

面板只监听 `127.0.0.1`，所有接口过 token 鉴权；浏览器拿到的是独立会话凭据，不是后端的主 token。
