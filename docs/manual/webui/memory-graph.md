# 记忆联想网络

记忆之间「总是一起被想起」的那张边，以及从任意一条出发的扩散结果。边的来源与
扩散算法见[记忆系统](../../dev/architecture/memory.md)。

## 顶部统计

「刷新」按钮旁的「包含已冻结的边」开关决定统计与图是否计入冻结边。统计卡六个：

- **节点**：三层记忆（事实 / 情节 / 知识）的指针总数。
- **边**：一起被想起过的记忆配对数。
- **活跃边 / 已冻结**：正在参与扩散的边数；跌破冻结线的暂停参与但未删除。
- **孤立节点**：还没和谁一起出现过的记忆。孤立不是异常——单条事实第一次入库时
  都是孤立的，被召回几次与其他记忆共现之后才会长出边。
- **扩散跑过**：事件账本里真实扩散的次数。扩散只在她主动选择「回忆」动作时发生；
  建了很多边但一次都没跑过时，页面会直接说明这一点，并建议用扩散预览先看看会
  牵出什么。

## 联想网络图

图是交互画布：拖拽节点可以把缠在一起的部分拉开，滚轮缩放，空白处拖动平移，
「复位视图」回到初始位置。节点过多时只画连接最密的 200 个，副标题会写明——
所以低连接度的节点可能不在图上，这不代表它没有边；顶部统计卡的边数是全量数字，
与画布下方图注里的实际绘制数（如「200 个节点，959 条边」）各是各的口径。三种
节点的读法：

| 节点 | 是什么 |
| :--- | :--- |
| 事实 | 她记得的关于某个人的事 |
| 情节 | 你们一起经历过的一段对话 |
| 知识 | 与具体某个人无关的概念与常识 |

圆点大小是连着的边数——越大越是枢纽，牵一发动全身；深浅是当前留存度，越淡越
接近被遗忘；连线粗细是两条记忆一起被想起过的次数；虚线是已跌破冻结线的边，
暂停参与但没有被删除。

## 节点详情与扩散预览

点任意节点，右栏从图例换成该节点：类型与编号、正文原文，以及留存、连边、命中、
人物、更新时间几个标注。记忆本体已删除时这里会提示「图上只剩下指向它的指针」。

「从这里扩散」用她真实使用的那份扩散实现跑一次预演：只读，不建边、不改库；与
真机的唯一差别是面板没有对话上下文，因此不含「刚才聊到过」的短期加成。结果列为
「顺带想起来的」，每条标注几跳与得分——跳数是离种子的边数，得分是这条被牵出来
的强度；点一条直接跳到那个节点。图上命中节点与种子各有一圈外环，一眼分出起点
和被牵出来的。下方「直接相连」列出全部邻居与边强度（冻结的标「已冻结」），同样
可点击跳转；某个节点牵不出任何东西时，页面会说明是邻居留存度太低被跳过。

扩散涉及的召回参数（PPR 跳数、回迁概率等）在[检索调优](retrieval-tuning.md)页；
逐条改记忆本体在[记忆管理](memory-manage.md)页。

## 节点与本体

图上的节点是指针，不是本体：正文存在各记忆层里，本页只负责把它们之间的边画出来。
删除一条记忆后，指向它的指针与边不会立即消失，详情栏会明确提示，直到后续清理
把它们收走。边在会话学习期间统计生成——两条记忆总是一起被想起，就长出一条边并
随共现加粗；因此边数跟着真实使用走，不是固定图结构。

新库或几乎没聊过的部署里，这一页可能是空图：统计全为零，画布区只有图例。这是
正常状态，不是加载失败；聊出记忆之后边自然出现。
