# 记忆管理

逐条检视人物事实：标失效与恢复、永久保留、人工取代、同槽冲突裁决；任何一步做错
了，都能在操作流水里撤销。事实从哪来、怎么衰减，见
[记忆系统](../../dev/architecture/memory.md)与
[core-memory 模块](../../dev/modules/core-memory.md)。

页面顶部「选择人物」下拉按人过滤，默认聚焦第一位有事实的人物；右侧「刷新」重取。
内容区分三个页签。

## 人物事实

事实表列：ID、正文、槽位、类型（身份 / 事件 / 偏好 / 习惯 / 关系 / 状态）、来源
（`legacy` 迁移存量 / `group` 群聊学得）、留存度（当前百分比，随衰减曲线下降）、
状态（活跃 / 已失效 / 已冻结 / 永久保留）、操作。「显示已失效」开关控制要不要
列出失效行；**粉色行处于待裁决的冲突组**。

类型是抽取链路打的分类：身份是「这个人是谁」的长期属性，事件是发生过的事，偏好
是好恶，习惯是重复行为，关系是她与对方的连接，状态是正在进行的近况。分类决定
衰减节奏，也决定哪些字段算同一槽位。

**槽位**是同一类事实的单一坑位（如「居住地」「职业」）：抽取链路写新事实时会
取代同槽位的旧值，槽位为空的行显示「—」。同槽位并存多条活跃事实时进入冲突组，
等人工裁决。

行内操作四个，各管一件事：

- **标失效**：确认框写明「标失效后该事实不再进入召回与提示词，但保留记录，随时
  可以恢复」。失效行只剩一个「恢复」按钮。
- **恢复**：把失效事实放回召回。
- **永久保留**：这条事实不再衰减（半衰期推到极远），行上出现「永久保留」标注；
  再点一次是「取消永久保留」，回到自然衰减。
- **改成…**：人工取代。弹窗里填新正文，确认后**原事实被取代并失效，新正文作为
  一条新事实入库**，页面回报新事实的 ID；与原内容表达同一件事的正文会被拒绝。
  误改可在操作流水里撤销。

## 冲突组

同一槽位并存多条活跃事实时自动成组。每组成员列出 ID、正文、来源、留存度与更新
时间，各自带「保留这条」按钮；确认框写明保留该成员、组内其余条目将被标失效。
裁决同样进操作流水，可撤销。

## 操作流水

全部人工与自动链路改动的台账，按时间倒序，默认按当前选中人物过滤、最多显示最近
50 条。列：时间、操作者（人工或自动链路）、操作（人工取代 / 标失效 / 恢复 /
永久保留 / 冲突裁决等）、事实（ID 与正文）、关联事实、状态，以及每行末尾的
**撤销**按钮。

撤销把那一步翻回去，按操作类型分三种：失效类（标失效、恢复、裁决）恢复取代指向
的原状；永久保留与取消永久保留写回当时的衰减字段；取代类除恢复原行外，把当时
新建的那行标失效退出召回——撤销产生的新行不物理删除。同一操作不能重复撤销，
撤销操作本身也不能再撤销。

## 与相邻页面的分工

本页只管**人物事实**这一层。表达方式、黑话词表的复核在各自页面；表情包在表情包
库页；导入批次的撤销在导入中心页。看一个人物的全部事实（只读）用
[人物与关系](persons.md)；看事实之间的联想边用[记忆联想网络](memory-graph.md)。
流水里「操作者」列的自动条目（抽取取代、反馈纠错）同样可以撤销。
