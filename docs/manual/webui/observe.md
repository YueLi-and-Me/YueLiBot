# 会话观察

面板首页，只读：整条回合链路里发生了什么，在这里翻。页面从上到下依次是运行总览、
事件账本、提示词工作台、实时日志四段，侧边栏「会话分区」就是这四个锚点。回合链路
本身的设计见[一次回合的完整链路](../../dev/architecture/conversation-turn.md)，
事件格式与重放机制见[可观测性](../../dev/architecture/observability.md)。

## 运行总览

顶部的「会话流」下拉按出口切换观察对象（桌宠、QQ 私聊、QQ 群聊各一条流）。旁边的
「自动刷新」开关默认关闭；关闭时点「刷新快照」手动取一次，卡片下会标注读取时间，
打开后按固定节奏自动取。

快照分三块：

- **四张状态卡**：当前状态（她正在做什么的一句话描述）、今日预算（主动开口额度
  已用 / 总额与攒满还需多久）、视觉响应（看几眼、开口几次）、会话人物（这条流里
  出现过谁）。
- **此刻在做什么**：所有会话各停在管线的哪个阶段、停了多久、进行到第几轮。被判
  「不回复」的会显示判定原因（如 `low_necessity`），失败会显示具体错误。
- **快照分区**：自身状态（精力 / 心情进度条）、活动时间线（每段活动的起止、来源
  `decided` 或 `backfilled`，可翻页）、今天的方向（主题与各意向的推进状态）、
  打扰预算（主动额度与兴趣值）、感知与视觉、会话状态（工作记忆条数与出现人物，
  点人物名跳[人物详情](persons.md)）、语音与缓存。

## 事件账本

按轮次聚合对话、按时间排列后台事件。顶部「事件类型」下拉过滤十七类事件——从
收到用户消息、回复门控判定，到请求模型、黑话命中、视觉扫视。计数行显示
「N / 1000 条 · 已跳过 M 条」：内存里只保留最近 1000 条，更早的靠检索。

「历史事件检索」按当前会话开关、轮次、类型、起止时间组合过滤，「检索历史」出结果，
「更早事件」按游标继续往前翻。两类展示：

- **对话轮次**：一回合一张卡，标注事件数与耗时；「查看该轮全部事件」展开完整列表。
- **后台事件**：逐条按时间排。`请求模型` 条目展开后能看到提示词模板名、指纹、
  温度与渲染参数；`prompt_record` 条目给出本次调用落盘的 JSON 路径
  （`data/logs/prompt/<任务>/` 下）。

`请求模型` 条目上有**用当前模板重放**：拿同一个请求、现在的提示词模板再调一次
模型，把原提示词指纹与新指纹、原输出与新输出并排显示。重放是真实模型调用，会计费。

## 分阶段调用记录

每次模型调用一份，按任务分目录。左侧「模型任务」下拉按任务过滤（chat、replyer、
planner、memory 等），每条记录显示时间、任务与会话 / 回合、模型、首字耗时、总耗时、
产字数，失败的记录带失败原因。点开任意一条可以翻回「这一级收到什么提示词、答了
什么」，控制台上只能看到最后一级的产物，这里能把每一级都翻出来。每页十条，翻页
按钮在列表底部。

## 提示词工作台

所有提示词模板的查看与覆盖入口。「模板」下拉按名字选，右侧显示来源、内容哈希、
占位符列表和权限；「生效内容」里可以直接编辑，「校验并保存」写入覆盖——之后每次
调用都用新内容，「删除覆盖并恢复内置」撤掉覆盖回到内置版本，没有覆盖时这个按钮
是灰的。「查看内置版本」对照内置原文；每次保存都会在「版本历史」里留一份归档。

两类模板不可编辑：`chat.discipline` 与 `chat.boundaries` 是固定模板，权限一栏会
标注只读。另外，覆盖的保存与恢复接口只接受来自回环地址的请求，从非本机来源打开
的页面只能看。

## 实时日志

恒定深色的终端视图，接后端日志流，头部显示连接状态与当前条数。日志按 ANSI 解析
保留颜色与粗体，新行到达自动滚到底部，偶数行带斑马纹方便对行。刷新页面或重连后
从头开始收，历史日志仍要看后端日志文件。
