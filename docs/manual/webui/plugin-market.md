# 插件市场

在管理面板「配置」分组打开「插件市场」。左侧按名称、说明、插件 id 搜索，也可按分类
筛选；右侧展示作者、许可证、来源、主程序版本支持区间与依赖。官方源的完整说明通过
「在商店页查看完整说明」链接打开，管理面板只展示清单信息。

## 浏览与安装

页头显示索引源和自动安装依赖状态。需要调整时编辑 `config/plugin_market.toml`，
保存后重启；刷新按钮重新拉取索引。不同源出现同一 id 时采用配置中排在前面的源，页面
会显示冲突与被忽略的来源。拉取失败的来源及原因单独展示，其余来源仍可浏览。

选择插件与版本后点击「安装所选版本」，阅读权限提示并确认。不兼容或已经撤回的版本
不能安装；兼容模式与明确开启的强制兼容遵循主程序已有规则。包下载后会检查大小、
SHA-256、归档路径和清单身份，再写入 `plugins/<id>/`。安装成功显示「重启后生效」，
需要手动点击「重启月璃」并再次确认，安装操作不会自动重启。

第三方插件与月璃运行在同一进程，能够读取全部配置（包括模型密钥）和数据库。
收录审核与完整性校验均不能保证插件没有问题；自行添加的索引源也需要由部署者判断可信度。
自动安装的库来自 PyPI，库本身的源码不在插件审核范围内。

## 从商店一键安装

插件商店网站的「一键安装」按钮会打开本机管理面板的插件市场页，地址形如
`<管理面板地址>/plugins?install=<插件 id>&version=<版本>`。面板选中该插件与版本后，
弹出与「安装所选版本」相同的确认框，点击确认才开始安装；已由市场安装的插件改为升级
确认，同 id 的手动安装插件改为「交给市场管理」确认。

链接只用来定位插件与版本，插件名称、说明与兼容判定都取自面板已配置的索引源。打开
链接不会直接安装，任何网页都可以放这样的链接，确认这一步不能省略。插件不在索引中、
版本已撤回或不兼容时，页面显示原因，不弹确认框。未登录时先完成登录，确认框随后出现。

商店默认跳转到 `http://127.0.0.1:7999`。管理面板改过端口、或通过 SSH 隧道映射到
其他本地端口时，在商店页点击按钮下方的「修改」填写实际地址，浏览器会记住这个设置。

## 升级、卸载与备份

有新版本时，详情显示可升级版本；「工具与 MCP」页头也会提示数量并链接到市场。
选择目标版本后升级，原配置 `config.toml` 保留。若插件代码被手动修改，升级会拒绝
覆盖并列出文件，需要先处理这些修改。

升级、卸载与接管手动安装插件时，旧目录连同 `config.toml` 移到：

```text
plugins/.backups/<id>-<旧版本>-<YYYYmmdd-HHMMSS>/
```

每个插件保留最近三份备份，旧备份会清理。备份与插件位于同一目录下，数据目录放在
其他磁盘时升级与卸载同样可用；`.backups` 不会被当作插件加载。卸载不会删除插件写在
月璃数据目录中的数据，也不会卸载它使用的 Python 库。目录操作成功后仍需重启，当前
运行中的插件不会被热卸载。

手动安装且索引中存在同 id 的插件可点击「交给市场管理」。确认后将旧目录备份、
从索引安装所选版本并保留配置，后续即可使用市场升级与卸载。

## 手动安装插件

从商店详情页的版本表下载插件包，可按旁边的 SHA-256 自行核对。包内顶层目录就是插件 id，
直接解压到月璃目录下的 `plugins/`，形成 `plugins/<id>/_manifest.json` 与
`plugins/<id>/plugin.py`，随后重启。不要再包一层同名目录，也不要把运行配置替换成别人
的 `config.toml`。手动放置的插件与市场安装的插件使用同样的启动兼容性和依赖检查。

## 依赖自动安装与手动安装

默认情况下，月璃读取清单中的 `python_dependencies`，用 uv 把缺失的库安装到当前
月璃环境。安装锁定环境中已存在的库版本；同一个库在一个进程里只能使用一个版本。
升级月璃时 `uv sync` 可能移除额外库，下次启动会再次检查并补装。

如需自行检查后安装，在 `config/plugin_market.toml` 修改：

```toml
[dependencies]
auto_install = false
```

关闭自动安装、找不到 uv 或安装失败时，缺少依赖的插件会显示「依赖缺失」，原因原文
和完整手动命令显示在「工具与 MCP」页，也写入启动日志。点击「复制手动命令」，在
运行月璃的同一台机器执行，再重启。命令包含当前解释器路径、固定版本约束与插件需求，
应完整保留。已有库版本与插件要求冲突时，应选择兼容的插件版本；强行改动已有库可能
导致月璃启动失败。

所有市场读取操作需要登录；安装、升级、卸载和接管还要求请求从本机回环地址进入后端。
