# 月璃设置

直接在面板里编辑五份配置文件：读出当前值、改字段、存回文件。五份 TOML 的分工与
交叉校验见[配置体系](../../dev/architecture/configuration.md)；逐字段的含义与
默认值对照 [`config.example/`](https://github.com/YueLi-and-Me/YueLiBot/blob/main/config.example/README.md)。

## 页面结构

顶部三个按钮：「重新读取」丢弃改动，「保存配置」校验并写文件，「重启后端」弹
「重启月璃」确认框后重启进程、约两秒后页面自动刷新。**保存只写文件，改动要重启
后才生效**；重启前有未保存的改动，确认框会提示。

五个标签页对应五份文件，每份内按段落分组，每个字段自带说明：

| 标签 | 文件 | 覆盖范围 |
| :--- | :--- | :--- |
| Bot 与人格 | `bot.toml` | 身份与关系、群聊策略、每日方向与活动、人设与说话方式、对话与记忆、行动核心灰度、气泡切分、追问与静默、表情包库、孤儿清理、桌宠 |
| 功能开关 | `features.toml` | 语音、屏幕视觉与隐私、感知出口、向量召回、命令通道、反馈纠错、日志、代理 |
| QQ 适配器 | `adapter.toml` | 协议端连接、owner 身份、私聊与群聊名单 |
| 模型厂商 | `providers.toml` | 厂商连接（密钥不回传明文） |
| 模型与任务 | `models.toml` | 模型条目、任务候选、按任务的生成参数 |

字段的说明文本来自配置生成器的 schema，控件跟着字段类型走：开关是拨杆，数字是
带范围校验的输入框，枚举是下拉，多行值（如群聊别名、临时说话方式候选）每行一条。
列表型字段可以增删条目，删除前有确认弹窗。QQ 适配器段由所选适配器插件提供，段名
随插件不同。

多行字段的一个例子——群聊别名一行一个称呼：

```text
小璃
璃宝
```

留空的含义各字段不同，字段说明里都会写：有的留空表示关闭该行为（如「对你的
称呼」留空则不主动使用特定称呼），有的表示沿用默认值，填错格式会在保存时被拦。

## 保存行为

保存是整体校验、整体写：任一文件校验不过，五份都不落盘，错误逐条列在页面上。
`providers.toml` 的密钥只保存到本机文件，页面读取时不会回传明文，已配置的密钥
显示为占位。

两处不在本页改的东西：厂商与模型的日常编辑在[模型与厂商](models.md)页（写的是
同一批文件，两边保存走同一套整体校验）；开发者命令的通道开关没有界面控件，只能
手改 `features.toml` 的 `[developer]` 段后重启，见[开发者命令](developer.md)。

## 改完怎么验证

重启后从对应页面复核：群聊策略看[会话观察](observe.md)的判定行为，模型与任务看
启动横幅与分阶段调用记录里的实际模型名，感知出口看屏幕感知行为的变化。字段取值
校验（范围、格式、引用关系）在保存时就会拦下，启动期的交叉校验是最后一道。

## 重启的影响

「重启后端」会让面板与 QQ 适配器短暂离线，进程拉起后自动恢复，无需人工干预；
正在进行的会话回合会在重启处中断，属正常现象。周期性重启没有必要——改了才重启，
没改就不动。

## 改坏了怎么办

加载期校验会指名道姓报出问题字段，面板保存前的校验已经挡掉大多数。文件被改到
面板打不开时，直接编辑 `config/` 下对应 TOML，或对照
[`config.example/`](https://github.com/YueLi-and-Me/YueLiBot/blob/main/config.example/README.md)恢复该字段的默认写法。
