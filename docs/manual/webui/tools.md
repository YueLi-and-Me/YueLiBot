# 工具与 MCP

在导航的「配置」分组打开「工具与 MCP」。左侧分为插件和 MCP 服务，右侧编辑选中项；底部统一保存，保存后重启后端生效。

## 插件

详情展示清单、来源、版本区间与加载判定，兼容提示和失败原因保留原文。工具的说明、所需能力和本轮可见判据来自插件声明。

配置表单由插件的配置模型生成。字典与列表使用单行 TOML 内联值，例如 `{ query = "{query}" }`、`["参数一", "参数二"]`；语法错误会立即标红并阻止保存。密钥字段不回传明文，显示「已设置」时留空会沿用原值。

被停用、版本拒绝或入口损坏的插件不会为了读取管理页而执行入口，此时只可修改启用开关。保存、重启并通过版本检查后，页面才能取得完整配置声明。

市场安装的插件显示安装方式、升级和卸载按钮。有新版本时，页头显示「有 N 个插件可升级」，
点击进入[插件市场](plugin-market.md)。升级保留 `config.toml`，代码被手动改过时会拒绝覆盖；
卸载将整个插件目录移入数据目录的 `plugin-backups/`，不会删除插件写在月璃数据目录中的数据。
每个插件保留最近三份备份，操作后需要手动重启。

手动放入 `plugins/` 的插件显示「手动安装」。索引中存在相同 id 时可选择「交给市场管理」，
确认权限提示后备份旧目录、安装索引版本并保留配置；后续可使用市场升级与卸载。

「依赖缺失」表示清单要求的 Python 库尚未满足，插件入口不会加载。页面原样展示失败原因，
若有手动命令可点击复制，在运行月璃的机器上执行后重启。自动安装开关、依赖冲突与备份
路径详见[插件市场](plugin-market.md)。

## MCP 服务

顶部开关控制 MCP 整体是否启用。新增服务后选择 HTTP 或本机程序接法，再填写连接参数。HTTP 可直接填写密钥或引用已有厂商密钥；切换到厂商引用会替换直接密钥来源。请求头可用 `{api_key}`，不含占位符的已存请求头、环境变量值都隐藏，留空保留，删除键则移除。

「测试连接」临时连接一次，展示协议、服务器信息与工具列表，最多等待 20 秒；不会保存、登记或开放工具。测试成功后仍需手动将工具列入配置，服务器没有只读标注时必须勾选「我确认只读」。开放给她关闭后，仅供插件调用；两者共用每日计数。

运行区展示最近错误、快照变化和实际开放判定。修改草稿不会改变运行状态，保存重启后才重新判定。说明变化应由你核对是否仍适合开放。

所有读接口都需要登录，保存和测试连接还要求本机回环访问。通过远程访问方式使用页面时，应确认请求最终从后端本机的回环地址进入。
