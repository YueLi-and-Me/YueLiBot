# 用量统计

只读页面，回答这几件事：模型一天用掉多少 token、花了多少钱、平均每条回复花多少；
这些 token 花在哪个任务、哪个模型、哪个会话，是主程序自己用的还是哪个插件用的；
各模型响应多快、稳不稳；哪家服务商根本不返回用量。侧栏在「观察」组、「会话观察」
下面，地址 `/usage`。

同一份统计还有两个出口，数字口径完全相同：每 15 分钟重写一次的报告文件，以及控制台
的用量汇总框，见本页后两节。

## 先填单价再看费用

费用 = 每次调用的用量 × **调用发生那一刻**生效的单价，在调用结束时算好累加进统计；
之后改单价不会回头重算已经记下的费用。因此：

- 没填单价（`price_in`、`price_out` 都是 0）的模型，费用一直是 0；
- 填单价之前产生的调用，费用永远是 0，填了之后的新调用才开始计费；
- 单价、缓存命中价与分时段价格的写法见 [models.toml](../configuration/models.md#单价缓存命中价与分时段价格)，
  也可以在 [模型与厂商](models.md) 的模型编辑框里填。

按模型分组的表里会列出每个模型**当前**的单价；单价为 0 的行会标出「单价为 0：未填写
或免费」，一眼分清是没填还是真的免费。

## 时间范围

顶部切换：本小时、今天、近 7 天、近 30 天、全部。「今天」「近 7 天」「近 30 天」按
浏览器所在时区的本地日计，含今天。统计按小时汇总存储，整点按 UTC 对齐；半小时时区
（如 UTC+5:30）的日界落在两个小时桶中间，按天统计会差 30 分钟。

## 总览

六张卡片：

- **调用次数**：每个实际发出请求的候选算一次，下面标出其中失败与中断的次数。候选
  切换时每个候选各算一次；同族跳过规则跳过、没有发请求的候选不算。
- **输入 token**：含缓存命中部分，下面标出缓存命中多少。
- **输出 token**：含思考部分，下面标出其中思考多少。
- **费用**：单位元，按上面「先填单价再看费用」的口径。
- **回复条数**：这段时间里她发出的消息条数。
- **每条回复**：平均每条回复的费用、token 与模型调用次数；没有回复时显示为空。

结局三种：正常结束、失败（以错误结束，含首字超时、格式不合格）、中断（用户打断，或
调用方拿到够用的内容后提前关流）。结构化校验失败的候选已经把整段输出生成完，服务商
照样计费，它的用量照记、结局记为失败。

## 服务商没返回用量

有的服务商、网关或旧接口不返回用量。统计**不估算**：这些调用计入「未返回用量」，
token 与费用都按 0 记。页面在总览下方单独提示「成功调用中有 N 次服务商没返回用量」，
并列出是哪个模型、哪家服务商。同一进程里某个模型第一次出现这种情况时，控制台还会
打一条警告。

对话请求一律带上 `stream_options.include_usage = true`，这是 OpenAI 兼容协议要求服务商
在流末尾返回用量的声明；某个服务商因此报错时，在该模型的 `extra_body` 里写
`stream_options = { include_usage = false }` 覆盖它，这样那家的用量就记为未返回。

语音合成不按 token 计量，只计次数与耗时，不算「未返回用量」。

## 趋势

两张柱状图：近 48 小时按小时、近 30 天按天，每张可在 token 与费用之间切换。柱子
悬停显示时刻与数值。

## 分组

四种口径切换，每组都给调用次数、失败 / 中断、输入、输出、缓存命中、费用、占比、
平均耗时与波动（标准差）：

- **按来源**：主程序，或某个插件（注明内置还是第三方）。插件代码里发起的调用都记在
  插件名下，包括插件请主程序代办的识图、看视频，以及插件派生出去的后台任务。插件
  等待的是主程序早先已经发起的同一个请求时（例如同一张图已经在识别中），这次调用记
  在主程序名下：谁真正发起请求就算谁的，避免同一次请求被记两遍。
- **按任务**：日常对话、行动决策、回复生成、记忆抽取等，中文名与模型页一致。
- **按模型**：模型名与厂商，另列当前单价。
- **按会话**：群名或私聊对象名；日程、摘要、记忆抽取这类不属于任何会话的调用显示为
  「后台任务」。

## 报告文件

`data/reports/usage.html`，随主程序启动生成一次，之后每 15 分钟重写一次。五个时间
范围都在这一个文件里，用页内的按钮切换；单文件自带样式与图表，不引用任何外部资源，
断网也能用浏览器打开，深色与浅色系统主题下都可读。服务器部署时面板只能走隧道访问，
把这个文件拷下来就能看统计。写入时先写临时文件再替换，打开时不会读到写了一半的内容。

文件里有群名与私聊对象名。它只保存在本机，不会上传；转发给别人之前留意这一点。

## 控制台汇总

与报告文件同一个定时任务：每 15 分钟检查一次，距上次打印有新的模型调用时，在控制台
打印一个「模型用量」框，内容是本小时与今天两栏的总览，加今天按来源、按模型费用最高
的前三名。期间没有新调用就不打印。

单次调用的用量在控制台的模型调用框里也能看到，形如「用量：输入 1,234 · 输出 56」，
服务商没返回时不显示这一行。

## 不上传

用量统计只存在本机数据库里，永久保留。匿名统计上报不包含任何用量、模型或会话
信息，见[匿名统计](../configuration/features.md#匿名统计)的上报口径。
