# 第八轮：把黑盒打开

用户的原话：「我看不到她的后台，所以对我来说是个黑盒。」

这不是验收不方便的问题。这个项目的核心命题是**持续性**——她记得、她会变。
**但如果用户看不见她在变，那变化就等于不存在。** 人格四轴两周从 40 漂到 65、
遗忘曲线冻结了哪条记忆、今天的日程是什么、她有没有看过屏幕——
现在这些全在 SQLite 里，一眼都看不到。做出来的东西有一半没有交付。

**这一轮要做两件性质完全不同的事，不许混在一起：**

| | P0-1 观察面板 | P0-2 她的内心 |
|---|---|---|
| 给谁 | 开发者（验收工具） | 最终用户（产品） |
| 长什么样 | 数字、表格、JSON，可以丑 | 她自己的话，绝无数字 |
| 在哪 | 新的独立窗口 | 扩现有日记窗口 |
| 目标 | 「我能查到当前状态」 | 「我感觉得到她在变」 |

**P0-1 不是 P0-2 的答案。** 把开发者面板直接给用户看，就等于把她变成一个
带进度条的养成游戏，角色感当场归零。反过来也一样，P0-2 里的模糊叙述验收时没法用。

---

## P0-1 · 观察面板（工具）

### 现状

`gate.inspect()` / `chat.inspect()` / `voice.inspect()` **都已经写好了**，
但只能从 selftest 路径调到（`src/main/index.ts` 里全部在自检函数内），
正常运行时没有任何 IPC 出口。缺的只是一个通道和一扇窗。

### 要展示什么

一屏能看完当前所有内部状态：

- **人格**：四轴当前值 + `describePersona()` 的自然语言输出（两个并排，方便对照映射对不对）
- **今天的日程**：完整 `DayPlan` —— `theme` / `bedtimeHint` / `wakeHint` / 全部 `slots`
- **睡眠**：当前 `probability`、`asleep`、`drowsy`、`naturalWakeTargetAt`、`sleepDebtDelayMinutes`
- **打扰预算**：`describeBudget()` 的全部字段 —— 今日已用、余量、冷却剩余、被无视次数
- **感知**：当前活动分类、持续时长、`visionStats` 全部（含 `byReason`，这是排查
  「为什么她从来不看屏幕」的唯一线索）
- **记忆**：L3 语义记忆全表 —— 内容、权重、`due_at`、是否已冻结；L2 情节条数；L1 轮数
- **语音**：`voice.inspect()` + 缓存命中统计

### 硬要求

**1. 只读。** 面板不能修改任何状态。它是观察窗，不是作弊器——
能改数值的话，之后所有「她怎么变成这样」的排查都不可信了。

**2. ⚠ 不许出现窗口标题原文。** `classify()` 在返回值里就把标题吃掉了，
`inspect()` 目前也没有泄漏。但面板是新的输出口，**必须加一条断言**：
构造一个带敏感标题的前台信息，断言面板数据里 grep 不到它。
这条红线从第一轮守到现在，不能在最后一米破在一个调试面板上。

**3. ⚠ `sandbox: false`。** 新窗口的 preload 是 ESM，不关沙箱会**静默失败**——
这个坑桌宠窗口和日记窗口各踩过一次，`notes.md` 里有 ⚠ 记录。照 `diaryWindow.ts` 抄。

**4. 入口在托盘。** 不要占用桌宠上的任何可视空间。

**5. 不要美化。** 表格 + 等宽字体就够。花在这上面的时间应该花到 P0-2。

### 验收断言

```
★ 面板数据里不含窗口标题原文
   注入 title = '工资表_2026Q3_客户名单.xlsx' → 面板 payload 中 grep 不到「工资」「客户名单」

★ 面板在正常运行时可达，不依赖任何 selftest 开关
   YUELI_SELFTEST 未设置时，IPC 仍返回完整数据

面板不提供任何写入通道
   preload 暴露的接口里没有任何 set/update/write
```

## P0-2 · 她的内心（产品）

### 目标

让用户**感觉得到**她在变，而不是被告知她在变。

### ⚠ 最硬的一条约束

**日记窗口里绝不出现任何人格数值。** 不是"不显示原始数字"，是连
「亲密度：很高」这种档位化的表述都不要。

这个项目从第一天就有条约束：人格数值只以自然语言进 prompt，永不以数字出现。
UI 同理。一旦用户看到进度条，她就从"一个人"变成"一个数值"，
后面所有的陪伴感都建立不起来了。

### 三个新区块

**1. 「今天」** —— 当天 `DayPlan` 用她的第一人称呈现。
不是时间表，是她的一天：`theme` 作为标题，`slots` 作为内容。
这是「她不在你面前时也在活着」最直接的证据。

**2. 「我记得的」** —— L3 语义记忆，按权重排序。

- **直接展示存储的原文**，不要让模型重写。用户要看的正是**她真的记住了什么**，
  重写一次就变成了表演。
- 已冻结（`retention` 低于阈值）的单独一组，标成「有点想不起来了」——
  **遗忘必须可见**。悄悄消失的记忆等于没有遗忘曲线；
  用户看到「有点想不起来了」，再主动提起、她"想起来了"，
  这条路径才是遗忘曲线真正的产品价值。

**3. 「变化」** —— 一句对比叙述，例如「最近好像比上个月更黏你一点了」。

⚠ **这一项需要先补数据：现在做不出来。** `persona` 表是单行 `WHERE id = 1`，
只有当前值，**没有任何历史**，无法做任何对比。

必须先加一张人格快照表（每天一条即可，几十字节），才谈得上"比上个月"。
先补快照，再做叙述——没有历史就诚实地不显示这一块，
**不要用当前值编一句听起来像对比的话。**

叙述的生成方式：取两个时间点的 `describePersona()` **自然语言输出**（不是数值）
交给模型，让它写一句对比。这样数值仍然不出人格模块，
和既有约束一致。

### 验收断言

```
★ 日记窗口的任何输出都不含人格数值
   构造四轴为特定值 → 渲染结果里 grep 不到这些数字，也没有档位词

★ 被冻结的记忆显示为「想不起来」，而不是消失
   构造一条低 retention 的 L3 → 它出现在"想不起来"分组里，不是不出现

没有历史快照时不显示「变化」区块，也不伪造
   快照表为空 → 该区块整体不渲染

人格快照每天最多一条，重复写入不产生多行
```

## 顺带确认一件事

P0-1 的 `visionStats.byReason` 上线后，请顺手看一眼实际数值并报告：
第七轮的 P1-4 要验「真实屏幕能不能自然触发」，
如果 `byReason` 显示常年卡在 `cooldown` 或 `no-change`，
那说明阈值需要调，而这个结论**只有面板能给出**。

## 不要做的事

- **不要把 P0-1 的面板做成用户功能。** 它是工具，不进任何面向用户的入口说明。
- 不要在 P0-2 里显示数值、进度条、百分比、星级或任何档位词。
- 不要让模型重写 L3 记忆原文。
- 不要在没有历史快照的情况下编造「变化」叙述。
- 不要为了面板好看而重构 `inspect()` 的返回结构。它现在被自检依赖，
  改了会连带影响前七轮的断言。加字段可以，改已有字段的名字和含义不行。
- 新窗口不要忘记 `sandbox: false`。

## 交付要求

- `npx vitest run` 全绿并报出新的用例总数
- 每条 ★ 断言**贴出改动前的失败信息**
- **真的开一次两扇窗**，各截一张图：面板要能看到当天 `DayPlan` 和 `visionStats`，
  日记要能看到「今天」「我记得的」两个新区块
- 人格快照表建好后，说明它什么时候写入、以及历史攒够之前「变化」区块的表现
- 有不同意的项写明理由，不要默默跳过
