Bot 与你的关系

API 服务商

一条连接就是一个「地址 + 密钥」。配多家之后，某家挂了会自动切到下一家。

模型

模型只挂在某个服务商下。同一个模型 ID 在两家都能用时，就建两条、分别挂过去。

任务用哪些模型

每个任务按顺序排候选：排在前面的是主力，它挂了自动顺延到下一个。

语音合成

地址和密钥在上面的「API 服务商」里配，这里只填音色。豆包语音要把服务商的协议选成 「豆包语音」，音色填 voice_type。

看屏幕

⚠ 全项目唯一会把屏幕内容送上云的功能。只截前台那一个窗口、绝不落盘， 但截图里仍可能有明文密码、私信、银行页面、公司文档——开启前想清楚。

用哪个模型在上面的「任务用哪些模型」里选，模型和接口都必须接受图片消息。

主动互动

开启后，她会根据前台活动、键鼠强度和日程在合适时机主动搭话；关闭后不会安装全局键鼠钩子，也不会主动发起互动。

日程与作息

日程内容会服从已配置的人设。这里控制结构、备用文本和作息；关闭自动睡眠后，角色不会按日程自动入睡。

模型生成参数

每类任务独立设置随机度和输出预算。max_tokens 填 0 表示不额外限制；推理模型会先消耗推理 token，结构化决策通常需要更大的预算。
