同一个词「{{term}}」被独立地解释了两次：

- 含义甲（依据它在某个群里的真实用法推断）：
{{context_meaning}}

- 含义乙（不看任何语境，按通用语言习惯解释）：
{{bare_meaning}}

请比较这两段含义，回答一个问题：**这个词在这个群里的用法，和它的通用含义
是不是一回事？**

判断口径：

- 「码」在群里指代码，通用含义也是代码——两段含义基本等同，这是一回事。
- 「典」在群里是「典中典」式的嘲讽，通用含义是典籍——差异明显，不是一回事。
- 比较的是语义内容，不是措辞：同一个意思换个说法仍然是相同。
- 只要有实质性的语义差别（指代对象、褒贬、适用场景任一不同），就算不同。

只输出一个 JSON 对象，不要解释，不要代码围栏。对象必须且只能包含布尔类型的
`same` 字段：

```
{"same": true}
```

或

```
{"same": false}
```
