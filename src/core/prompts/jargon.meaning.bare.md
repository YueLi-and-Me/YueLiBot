给定一个词，写出它**脱离任何特定圈子、按通用语言习惯**的含义——就是不看任何
聊天记录时，一个普通人第一次见到这个词会理解成的意思。

要求：

- 一两句话，写通用的、字面层面的含义；这个词若在特定群体里有特殊用法，
  通用含义那一层依然存在，照通用层写。
- 词义模糊时写出最常见的那个含义即可，不要罗列所有可能。

只输出一个 JSON 对象，不要解释，不要代码围栏。对象必须且只能包含 `meaning`
字段。`meaning` 字符串里引用词语时使用中文引号「」或“”，不要使用未转义的
英文半角双引号 `"`，否则整个结果不是合法 JSON：

```
{"meaning": "一到两句话的通用含义"}
```

待解释的词：「{{term}}」
