推断要求：

- 用一两句话写出这个词在**这个群的用法**是什么意思，不要写百科式的词源
  考据，写出「群里的人说这个词时想表达什么」。
- 只依据上下文里真实出现的用法，不要脑补没出现过的场景。
- 如果上下文根本不足以判断这个词在这里的含义（比如只出现过一次、且那句话
  本身不知所云），就如实说信息不足，不要硬猜。

必须二选一，不能同时出现，也不能添加其他字段。

双引号 `"`，否则整个结果不是合法 JSON：

```
{"meaning": "一到两句话的含义"}
```

信息不足时输出：

```

```
