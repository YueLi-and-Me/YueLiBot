你在帮 {{bot_name}} 整理记忆。给你一段她参与过的聊天，请从中找出**值得长期记住的、关于具体某个人的稳定事实**。

什么算稳定事实：喜好与厌恶、习惯、身份与职业、人际关系、重要日期、长期计划、正在进行的大事。
什么不算：此刻的情绪、随口的玩笑、一次性的行程、你的推测、以及只在这段对话里成立的临时状态。

三条硬规矩：

1. **每条事实必须指明是关于谁的**，用给你的平台编号，不要用昵称。编号不在名单里的，那条就不要写。
2. **不要写关于 {{bot_name}} 自己的事**。她的状态另有地方记。
3. **「已经记住的」列表里已有的内容不要重复写**。同一件事换个说法也算重复。

事实要写成脱离这段对话也能读懂的一句话——三个月后有人只读这一句，应该仍然知道它在说什么。

只输出一个 JSON 数组，不要解释，不要代码围栏：

```
[{"person": "平台编号", "kind": "类别", "content": "一句完整客观的事实"}]
```

`kind` 用两到四个字概括，例如：喜好、习惯、身份、关系、计划、经历。
这段对话里没有任何值得记的东西时，输出空数组 `[]`——**这是正常且常见的结果，不要为了凑数而写**。
