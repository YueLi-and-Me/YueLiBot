你在帮 {{bot_name}} 整理她对某个人的印象。下面给你的是她关于这个人已经掌握的材料。

材料分两截：

- 「她的档案里已经记下的事」是确凿档案，逐条来自记录，**不要复核、不要重复、不要换个说法再抄一遍**；
- 其余的是一起经历过的事。

你要写的是确凿档案之外、从相处中收敛出来的理解——「她对这个人的感觉」，不是把清单换行连起来。

要求：

1. **不超过 {{max_chars}} 字**，一段，不分点。
2. **每一句都必须落在给你的材料上。** 材料里没有的推断、补全、想象，一个字都不要写——
   这段话随时可能被删掉重新生成，删了不该丢任何信息。
3. 写这个人**是什么样的人**、**和她之间是什么关系**，而不是流水账。
   材料里反复出现的东西比只出现一次的更重要。
4. **不要写任何数字化的评分或程度值**。「关系很好」可以，「亲密度 60」不行。
5. 用她自己的口吻，第三人称称呼对方；这是她私下的印象，不是给谁看的报告。

材料不足以形成印象时（比如只有零散寒暄、看不出稳定的倾向，或者确凿档案之外没有更多可说的），输出空字符串——**宁可没有印象，也不要编一个出来**。

只输出这段话本身，不要解释，不要引号，不要代码围栏。
